# 贪吃蛇算法赛

Windows 上解压整个文件夹，双击 start.bat。也可以在这个文件夹里执行 `node server.mjs`，然后访问 http://127.0.0.1:8787。通用下载包依赖 Node.js 18+ 和 PATH 中的 g++。无需安装 npm 依赖。

## 网站入口

- 封面（/）提供规则和普通测评两个入口。
- 规则（/rules）附可下载的 AI-PROMPT.md，以及测评区和天梯榜入口。
- 普通测评（/evaluate）支持两份 C++17 程序同批种子对照，最多 8 个种子。默认种子 20261121 可复现原测试，固定测试组含五个种子。各组十局的加权总分为 Σ 原始分/(log₂(N)+1)。
- 天梯（/ladder）按提交的最高加权总分排序。参加时填写昵称和模型，也可生成「用户」加 10 位数字的匿名昵称。
- 每轮天梯由服务端抽取 10 个不同种子，每组 10 局。取完整测试组的最高分，同轮同分取先测到的那组。没有完整结果时无法上榜。
- 天梯成绩在按下「确认上传」后才保存。详情展示源码、十组逐局成绩，以及最高分组的逐步回放。未上传结果在服务端重启后失效。

天梯记录存放在项目下的 `data/ladder/`，关闭服务不会清空记录。备份或迁移时保留这个目录。网站仅监听本机，榜单是此实例内共享的。服务会以当前用户权限编译运行提交的 C++，请使用信任的源代码。
## 命令行测评

运行 `node arena.mjs --help` 查看命令。check 检查一个十局测试组，run 自动编译并跑多个种子，show 从 JSON 打印某一步的棋盘。规则页可下载独立测试包，适合交给有终端权限的 AI。参赛者最终只交一个 snake.cpp。
